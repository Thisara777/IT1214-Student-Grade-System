# IT1214-Student-Grade-System
Student Grade Management System 

## Project Purpose

This is a Java console-based application developed using Object-Oriented Programming (OOP) concepts.

The system allows to:

* Add student records
* Display all student records
* Search students by Student ID
* Calculate average marks

## Technologies Used

* Java
* OOP Concepts
* GitHub Version Control

## How to Run

1. Compile the Java files:

javac Student.java StudentGradeManagementSystem.java

2. Run the program:

java StudentGradeManagementSystem

3. Use the menu to manage student records.
